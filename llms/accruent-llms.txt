# Accruent

> Workplace, facilities and asset management software for the built environment — CMMS/EAM,
> engineering document management, IWMS and lease accounting, space and event scheduling, telecom
> site management and IoT condition monitoring. More than 10,000 customers in over 150 countries.

> does not publish an llms.txt of its own (probed: 404 on all 8 Accruent-controlled hosts).

## What is machine-readable

Only one Accruent API publishes a machine-readable contract without a login: the Maintenance
Connection Web API, as a Swagger 2.0 document with 126 paths and 255 operations. Authentication is
HTTP Basic over a base64 "ConnectionKey:APIKey" token; filtering, sorting and paging use a
documented subset of OData query options; the rate limit is 200 requests per minute and is
signalled with a 403, not a 429. There is no DELETE operation anywhere in the contract and no
idempotency mechanism, so writes made through this API cannot be replayed safely or taken back.

- [Maintenance Connection Web API reference](https://api.maintenanceconnection.com/v8/help/docs): human docs for the v8 schema
- [Maintenance Connection Swagger 2.0](https://api.maintenanceconnection.com/v8/swagger/docs/v8): the contract itself
- [Maintenance Connection Swagger UI](https://api.maintenanceconnection.com/v8/swagger/ui/index): try-it console
- [Authentication](https://api.maintenanceconnection.com/v8/help/docs/AuthenticationDocs): Basic ConnectionKey:APIKey
- [Requests and filtering](https://api.maintenanceconnection.com/v8/help/docs/RequestDocs): OData $filter/$top/$skip/$orderby, 200-record batches
- [Responses and error codes](https://api.maintenanceconnection.com/v8/help/docs/ResponseDocs): the full status table, including the 403 rate limit

## APIs behind a wall

- [Siterra API](https://developer.accruent.com/wiki/siterra/gettingstarted): telecom site and project lifecycle. Base https://api.accruent.com/siterra/us/, auth via the accruent-subscription-key header. Requires an invitation into the Accruent Developer Program; the anonymous Azure APIM catalogue at developer.accruent.com exposes only the stock Echo API sample.
- [Meridian Cloud API](https://help.accruent.com/meridian/Content/Online_Help/Cloud_Portal/Integrations/MeridianCloudAPI.htm): engineering document management — asset, relationship and contractor package APIs. Auth via Ocp-Apim-Subscription-Key. Base URL disclosed only to approved subscribers per region.
- [EMS Platform Services](https://help.accruent.com/ems/Content/EMSPlatformServices/InstallationGuide/Introduction.html): space and event scheduling REST APIs with JWT auth. Swagger ships inside the deployment at {your-host}/EmsPlatform/swagger, so there is no public definition. Replaces the EMS SOAP API Web Service, which Accruent states is no longer being developed.
- [Lucernex REST API](https://help.accruent.com/lucernex/Content/Online%20Help/00_Advanced_Content/API_Documentation/1_IntroductionToAPI.htm): IWMS and lease accounting. XML-first; the schema browser is served from the customer tenancy.

## What Accruent does not publish

- No /.well-known/ surface of any kind — no security.txt, no OpenID or OAuth metadata, no api-catalog, no apis.json (probed on 8 hosts, all 404)
- No A2A agent card at either the canonical or the legacy path
- No MCP server, hosted or stdio
- No first-party SDK for any API
- No webhooks, events or AsyncAPI surface
- No API deprecation policy, Sunset header support, SLA, or developer changelog
- No vulnerability disclosure or bug bounty programme
